# Home page content (Payload CMS)

The landing page at **https://srrcareers.in** is edited in **Globals → Home Page**. Tabs follow the live page top to bottom. Click **Save** when you finish — then refresh the site to see updates.

## Edit the homepage

1. Open **https://srrcareers.in/admin** and go to **Globals → Home Page**.
2. Use the numbered tabs:

| Tab | Section on the page |
|---|---|
| **1 · Hero** | Headline, buttons, hero image |
| **2 · Problem** | “Does this relate…” section |
| **3 · Mission** | Stats cards and alumni block |
| **4 · Instructor** | Bio and feature bullets |
| **5 · Curriculum** | Module list and syllabus button |
| **6 · Testimonials** | Student quotes |
| **7 · Book a demo** | Bottom blue section |

## Images

1. Go to **Collections → Media** and upload a file (add a short **Image description**).
2. On **Home Page**, pick that image for **Hero photo** or **Instructor photo**.
