# CMS & landing page guide

How to update the SRR Careers website from the admin panel. Content edits go live after you click **Save**.

**Live site:** https://srrcareers.in  
**Admin:** https://srrcareers.in/admin

---

## Opening the CMS

1. Go to **https://srrcareers.in/admin**.
2. Sign in with your admin account.
3. Use the left sidebar:
   - **Global** — things shared on every page (header, footer, contact).
   - **Website Pages** — the landing page and other page content.
   - **Collections** — images, individual courses, workshops, blog posts.

---

## Landing page (Home)

The homepage at **https://srrcareers.in** is controlled by **Globals → Home Page**.

Tabs match the page from top to bottom:

| Tab | What it controls on srrcareers.in |
|---|---|
| **1 · Hero** | Top banner: small label, headline, two buttons, large photo |
| **2 · Problem** | “Does this relate…” heading and the six pain-point boxes |
| **3 · Mission** | “Our Mission” heading and the stats / alumni cards |
| **4 · Instructor** | Instructor photo, bio, and feature bullets |
| **5 · Curriculum** | Module list and syllabus button |
| **6 · Testimonials** | Student quotes |
| **7 · Book a demo** | Bottom blue “book a demo” band (copy and buttons) |

### Tips for the hero

- **Main headline** and **Highlighted headline** are the two lines of the big title.
- **Primary button (gold)** and **Secondary button (outline)** each need button text + a link (e.g. `/courses` or `#book-demo`).
- **Hero photo** — pick an image from Media (see below). Leave empty to keep the default image.
- **Hero photo description** — short alt text for accessibility.

### After editing

Click **Save** (top right). Refresh https://srrcareers.in to see changes.

---

## Images

1. Open **Collections → Media**.
2. Upload a file and fill in **Image description**.
3. Back on **Home Page** (or any other page), choose that file in the photo field (e.g. Hero photo, Instructor photo).

---

## Shared site chrome (header & footer)

**Globals → Site Settings** controls what appears on every page:

| Tab | Use for |
|---|---|
| **Brand & Header** | Site name, tagline, top strip, header button |
| **Navigation** | Main menu links (and dropdowns) |
| **Contact** | Phone, email, WhatsApp |
| **Social** | Social profile links |
